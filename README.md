# 🌌 Cyberpunk Tech TODO List (赛博朋克暗黑科技风待办事项系统)

这是一个基于 **Flask + SQLite3** 后端以及 **原生 HTML5/CSS3/JavaScript** 前端构建的、具有强烈暗黑科技/赛博朋克视觉风格的个人高效待办事项（TODO List）管理系统。系统针对现代打工人、程序员的设计语言进行了深度视觉定制，支持多维度的任务看板与日历视图切换。

---

## 🌟 核心特性

1. **赛博朋克视觉风格**：深色暗黑底色（Cool Slate/Dark Navy），搭配高饱和度霓虹发光元素（Neon Cyan & Pink），极细科技感滚动条，打造极具沉浸感的数字工作流环境。
2. **多视图智能切换**：
   - **主看板视图**：按季度/月份三栏式排布，任务状态一目了然。
   - **卡片日历视图**：原生集成中国农历（Lunar Calendar）与法定节假日/二十四节气提示（免第三方前端库，后端无缝解析）。
3. **独创“主要矛盾”远期目标管理**：
   - 允许维护多条远期目标，并支持一键切换。
   - 独创“焦点回归机制”：浏览其他目标时，若失去焦点或停止操作 **5 秒后**，系统会自动丝滑切回当前阶段的“主要矛盾”，确保核心专注力不涣散。
4. **智能跨月迁跃与跨天校准**：
   - **跨月迁跃**：历史未完成的任务在进入新月份时，会自动滚动并“迁跃”至当前月份的“待定（TBD）”区域，拒绝死板过期。
   - **页面自动校准**：当网页重新获得焦点时（Focus），自动检测并更新跨天/跨月状态，无需暴力刷新。
5. **极速交互与丝滑动画**：
   - 全面引入 **FLIP 动画哲学**，无论是改变优先级、调整日期还是完成勾选，任务块重排均拥有物理级别的级联平滑缓动效果。
   - 支持**原生鼠标拖拽（Drag & Drop）**对当月待定任务进行直观的排序。
   - **智能自动聚焦**：创建新任务时，页面会自动平滑滚动并聚焦至新输入框。
6. **双端无感快捷键**：
   - **Windows 用户**：`Ctrl + Alt + N`
   - **Mac 用户**：`Cmd + Option + N`（系统自动识别 OS 并动态更新顶部视觉提示）
7. **数据备份与无缝迁移**：
   - 支持一键导出精确到分钟命名的 `.xlsx` Excel 备份文件。
   - 支持通过标准的 Excel 模板进行任务批量导入，并能智能识别加了“删除线”的已完成任务。

---

## 🛠️ 技术栈

- **后端 (Backend)**：
  - Python 3.x
  - Flask (轻量级 Web 框架)
  - SQLite3 (嵌入式关系型数据库)
  - openpyxl (Excel 读写处理)
  - chinesecalendar & zhdate (中国农历与法定节假日计算引擎)
- **前端 (Frontend)**：
  - 原生 HTML5 / CSS3（自定义变量、Sticky吸顶特效、自定义Scrollbar）
  - 原生 JavaScript（Vanilla JS，纯事件驱动，FLIP重排算法）
